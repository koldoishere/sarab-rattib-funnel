# Rattib App MVP

All-in-one Arabic RTL freelancer toolkit (under **Sarab**): Pricing · Proposal · CRM · Weekly work.

## Run
Open `index.html` in a browser, or:

```bash
python3 -m http.server 8765
```

Then visit `http://localhost:8765`.

## MVP includes
- Live pricing formulas + editable FX (EGP per USD) + «للعرض» send-to-proposal
- Proposal deposit/balance + WhatsApp copy/open (includes contact)
- CRM Arabic statuses + overdue highlight/count
- Weekly Done ☐/☑ with today-row highlight
- localStorage + JSON export/import

## Not in MVP
- Accounts / sync / payments
- Native mobile installs
